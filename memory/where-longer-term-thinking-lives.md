Decided 2026-11-07. Open ideas, the picture of a possible agent harness and ideas from users are collected in `VISION.md`, not in `ROADMAP.md`. The roadmap lists only what is planned and in which order. The observations table in `VISION.md` comes from the session that built the first version and is the evidence base for what an agent harness should prevent; it is not a list of complaints.

**Why:** a roadmap with undecided ideas in it stops being a plan.

**How to apply:** when an agent or a person hits a problem a harness could prevent, add a dated line to `VISION.md` (what happened, not what is assumed). When an idea is accepted, move it into the roadmap with a milestone and leave a one-line note in the ideas log.
